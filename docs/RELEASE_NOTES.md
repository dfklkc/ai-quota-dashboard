## v1.0.3

API 用量改为跟随 CC Switch 当前提供商，并增加中转站用量分析。

- 从 CC Switch 只读获取所选客户端的当前地址与凭证；支持 Claude Code、Claude Desktop、Codex、Gemini，不复制 Key、不修改其数据库。
- 自动跟随提供商/Key 切换，清除旧来源的退避影响；只查询一个选定客户端，避免轮询无关提供商。
- 支持 NewAPI Key 用量、已配置账户凭证的钱包余额和 Sub2API 用量。仅向配置对应的 HTTPS 同源站点发送只读查询，拒绝重定向；不执行自定义脚本。
- 展示站点返回记录内的今日/近7日调用数、输入+输出 Token、费用及主要模型；最多1000条日志，不冒充完整账单。
- 日志不可用时区分 CC Switch 本机估算与站点账单；未取得的数据明确显示未提供。无限额 Key 的有效累计用量不再误报整体未连接。
- 同一中转站用量与分析约5分钟查询一次，HTTP 429 后至少退避5分钟；每分钟检查提供商切换，手动刷新可立即更新；仅缓存聚合值，排除原始日志、请求内容、IP 和 Key。
- 保留旧 LinksAPI/Claude 配置兼容选项；默认配置和发行包自检同步更新。

验证：107 项 Python 回归检查、44 项显示/缓存/配置/进程检查、19 项 AppKit 窗口检查；真实 CC Switch 只读读取及站点查询；通用安装包与运行时离线验证。

## v1.0.2

减少无用后台工作，并修复来源状态、配置保存和异常接口处理。

- 空闲时不再运行每秒进度定时器；只在查询且卡片可见时刷新进度，隐藏或完全被其他窗口遮挡时暂停界面时钟。
- 缓存未变化时不重复读取内容、解码和发布界面状态；位置在移动后合并保存，不再每分钟重写。
- 全部来源停用时不启动查询进程；停用来源和正常退避期间不再执行无效查询、导入或重复缓存写入。
- 子进程完成通过信号等待，替代每秒十次的存活轮询，并保留总超时与终止保护。
- Chrome 跟随模式取得首个优先会话后结束，避免重复读取后台标签；固定邮箱匹配仍支持多会话查找。
- 修复只启用 Antigravity 或中转站时误报异常、损坏或删除的缓存保留旧值、清空用户 ID 无法生效等问题。
- 配置损坏时拒绝覆盖；保存设置保留未知的账号选项，清理不可达的旧账号编辑界面代码和冗余配置双写。
- 布尔值、异常时长、非有限时间、坏套餐/重置包字段及损坏退避状态不再破坏整轮数据显示。
- GPT 带凭证的查询拒绝重定向，防止凭证跟随跳转。
- 新增公开内容与 Git 历史检查、后续维护规则及本机数据忽略规则；代码、文档和干净发行包公开，本机凭证与缓存不上传。

验证：80 项 Python 检查、38 项显示/缓存/配置/进程检查、19 项 AppKit 窗口检查；安装包及运行时离线验证。

## v1.0.0

AI 桌面卡片首个独立安装版本。

- 新增统一 macOS 图标，应用程序入口与安装包保持一致。
- 提供通用 PKG 和 DMG，支持 macOS 14+、Apple Silicon 与 Intel。
- 内置两种架构的 Python 运行时、Chrome 桥接和全部查询脚本，无需额外安装开发工具。
- 首次启动生成无凭证的默认配置，升级保留原有本机设置。
- GPT 跟随本机与 Chrome 登录账号，展示 Codex 使用额度；包含 Antigravity 与 LinksAPI 数据源。
- LinksAPI 区分 Key 用量与钱包余额；未取得的余额明确显示待配置。
- 安装包不含作者账号、API Key、浏览器会话或额度缓存。

验证：51 项 Python 回归检查；Apple Silicon 原生与 Intel/Rosetta 离线自检；现有配置保留；签名、PKG 解包、DMG 挂载和 SHA-256 校验。

此版本采用 ad-hoc 本地签名，尚未进行 Developer ID 签名和 Apple 公证。下载后 macOS 可能要求用户在系统设置中确认来源。

下载 `.pkg` 直接安装，或打开 `.dmg` 后将应用拖入 Applications。`SHA256SUMS.txt` 用于校验下载文件。
